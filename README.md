# Python (Django) GraphQL MCP Server

MCP server for Python (Django) GraphQL integration.

## Setup

```bash
npm install
npm run build
npm start
```

## Development

```bash
npm run dev
```

## Structure

- `src/` - Source code
  - `handlers/` - MCP tool handlers
  - `types/` - TypeScript type definitions
  - `utils/` - Utility functions
- `dist/` - Compiled JavaScript
